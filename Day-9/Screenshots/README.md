# Day 9 – Interactive Lightning Web Components

## Work Done

- Built the **Apply workflow** in the Eligible Jobs component.
- Added **Apply button and event handling**.
- Implemented **imperative Apex** for application submission.
- Reused the existing **Application Service** for business logic.
- Added **loading, success, and failure states**.
- Handled **duplicate application attempts**.
- Refactored the UI into **Parent and Child LWC components**.
- Implemented **Parent-to-Child communication using `@api`**.
- Implemented **Child-to-Parent communication using Custom Events**.
- Added UI refresh after successful application.

## Outcome

The Eligible Jobs component was made interactive, allowing students to apply for jobs directly through the LWC.

## Technologies

- Salesforce LWC
- JavaScript
- Apex
- Imperative Apex
- Custom Events
