# Day 4 - Lightning Web Components (LWC)

## 1. What is LWC?

Lightning Web Components (LWC) is Salesforce's modern programming model for building fast, reusable, and lightweight user interface components. LWC is based on standard web technologies such as HTML, JavaScript, and CSS.

---

## 2. What did you build?

I built a Placement Management System home page using Lightning Web Components. The application includes:

- Placement Portal dashboard
- Student details (Name, Roll Number, Department)
- Show Welcome Message button
- Apply button to change the application status
- Display of today's date
- Dashboard showing:
  - Number of Companies
  - Number of Jobs
  - Applications Submitted

---

## 3. Which file contains HTML?

The HTML code is written in:

```
placementHome.html
```

This file contains the user interface of the Lightning Web Component.

---

## 4. Which file contains JavaScript?

The JavaScript code is written in:

```
placementHome.js
```

This file contains variables, button click handlers, and the component logic.

---
